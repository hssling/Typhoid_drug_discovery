# 🌍 Global Enteric HDT Discovery Portal

The **Typhoid HDT Explorer v4.0.1** is an authentic, evidence-based platform for identifying and prioritizing host-directed therapy (HDT) candidates for Enteric Fever (Typhoid and Paratyphoid).

## 📊 Methodology
The discovery engine utilizes a **Convergent Evidence** framework:
- **Authentic Transcriptomics**: Human clinical data (Thompson et al. 2009, Blohmke et al. 2018).
- **Causal Inference**: Human GWAS susceptibility loci (Dunstan et al. 2014).
- **Structural Bioinformatics**: RCSB PDB 3D structures and AlphaFold models.
- **Deep Learning**: GNN-MLP bioactivity prediction trained on ChEMBL SMILES records.

## 🚀 Key Features
- **Global Leaderboard**: Definitive rankings of host targets based on 5 discovery layers.
- **AI Predictions**: Prospective binding affinity (pChEMBL) for thousands of repurposing hits.
- **Pan-Enteric Scaling**: Broad-spectrum efficacy identified across Salmonella serovars.

## ⚖️ Scientific Integrity
This project is part of an Open Science initiative to restore scientific integrity to HDT discovery. Every result is traceable to peer-reviewed literature and verified bioinformatics APIs.

**Submitted to**: Journal of Infection in Developing Countries (JIDC).
